# GBBooking Logo Assets

Upload your official GBBooking logo into this folder.

Recommended filename:
- `gbbooking-logo.png` (transparent PNG)

You can also use `gbbooking-logo.svg` or `gbbooking-logo.webp`.

Once uploaded, the website header can reference the logo at `/assets/logo/gbbooking-logo.png`.

Keep the filename consistent, or update the logo path in `components/header.html` when using a different filename.
